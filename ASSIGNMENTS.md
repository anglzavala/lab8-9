## Add an assignment to the website

1. Write down its actual title, requirements, artifacts, and what you learned.
2. Add or adapt a project card in the `#work` section of `index.html`.
3. Add the assignment's explanation to `explainAssignment()` in the inline script, matching the assignment number used in the page.
4. Check chatbot replies against the page content; do not describe an unimplemented feature as complete.
5. Run the relevant checks in [`TESTING.md`](TESTING.md).

Keep private information, credentials, and real payment data out of coursework examples.
