The original idea

A portfolio that does more than show.

Problem: Student work can be scattered across tools and difficult to explore. Objective: bring portfolio work, assignments, interactive data, media, and a bounded AI site assistant into one accessible experience.

Who benefits? Students presenting their work, educators reviewing it, and visitors exploring it. Potential impact: make projects easier to understand and demonstrate practical interaction design.

Key features

Integrated project showcase, theme controls, data dashboard, voice/text assistant, mock shop, and media player.

What makes it different?

The assistant can trigger specific page actions, not just reply with text. Future work could add real assignment artifacts, richer visualizations, and more languages.

Security, privacy & documentation

Clear controls. No surprise checkout.

Voice recognition requires browser support and microphone permission; speech may be processed by the browser vendor. Text commands run locally in this page. The cart has no payment processor. Only use media you own or are licensed to share.

Limitations: the assistant recognizes a predefined set of commands, not every phrasing. Browsers can require a user gesture for media. Assignment details and chart values are demo placeholders; replace them with actual coursework.
